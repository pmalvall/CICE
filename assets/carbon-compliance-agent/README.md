# Carbon Compliance Intelligence Engine

An enterprise-grade AI agent that transforms SAP PRA hydrocarbon production data into audit-grade, regulatory-compliant carbon intelligence and ESG disclosures in real time.

## Overview

Uses A2A Protocol, LangGraph, LiteLLM, and SAP Cloud SDK.

## Structure

- `app/main.py` - A2A server entry
- `app/agent_executor.py` - Request handling
- `app/agent.py` - Agent logic
